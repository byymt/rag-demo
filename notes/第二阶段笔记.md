# 第二阶段学习笔记：LangChain + RAG 进阶

## Day 13 RAG 进阶：重排序 + 引用溯源 + 拒答去幻觉（13_advanced_rag.py）

基础 RAG 的三个问题及对策：

| 问题 | 方案 | 一句话原理 |
|---|---|---|
| 向量检索排序不准 | **重排序 Rerank** | 粗检索5片 → LLM逐片打0-10分 → 按分排序取top3 |
| 不知道答案出自哪 | **引用溯源 Citation** | 给文档编号[1][2][3]，prompt要求回答标注编号，末尾列文件名 |
| 资料没有也硬编（幻觉） | **拒答去幻觉** | 调LLM前看最高分，低于阈值5直接拒答，根本不调LLM |

整体链路：`粗检索(k=5) → LLM重排序 → top3 → 分数判断 →(合格)拼编号context → 带引用回答 /(不合格)直接拒答`

### 阶段A：LLM 重排序

- `rerank(question, docs, llm)`：每片文档拼进打分 prompt，`score = float(result.content.strip())`（LLM返回的是文本，要转数字才能排序）
- 成对存储 `scored.append([doc, score])`，排序 `scored.sort(key=lambda x: x[1], reverse=True)`（x[1]=取分数，reverse=降序）
- **必须 `return scored`**（整个列表），不能 return score（只剩一个数字，下游会崩）
- 列表推导式只留文档丢分数：`[doc for doc, score in scored]`
  - for 后的 `doc, score` 是**解包**（接住每对里的两个值）；for 前的 `doc` 是每轮要收集进新列表的值

### 阶段B：引用溯源

- `for i, doc in enumerate(top3, 1)`：第二个参数1让编号从1开始（默认0）
- 来源取元数据：`doc.metadata.get("source", "未知来源")` → `os.path.basename()` 只留文件名
- 编号拼上下文：`f"[{i}] {doc.page_content}"`，三片用 `"\n\n".join(...)` 连接（空一行分清边界）
- prompt 三句约束：①只能根据资料答 ②标注数字编号 ③没答案就说无法回答
- 回答取 `answer.content`（AIMessage 对象的文本属性）

### 阶段C：拒答去幻觉

- 阈值常量 `SCORE_THRESHOLD = 5.0`（经验值：实测相关片10分、无关片0分，取中间5）
- `top_score = top3[0][1]`：`top3[0]`是第1名的[doc,分数]，再`[1]`取分数（连续下标，中间无逗号）
- `if top_score < 阈值: 直接print拒答 else: 执行整个阶段B`
  - 拒答分支不拼context、不调LLM → 省钱且绝不可能幻觉（硬门槛，比prompt里"请不要编造"的软约束可靠）
- top3 每项变成 `[doc, score]` 后，循环解包要写 `for i, (doc, score) in enumerate(...)`（括号不能省）

### 验证方法

- 相关问题"没按时还书会怎么样" → 第1名10分 → 正常回答，逾期规则后带[1]
- 无关问题"怎么炒番茄炒蛋" → 全0分 → 只输出"根据现有资料无法回答"，无引用来源段

### 两条重排序技术路线对比

- **LLM 打分**（本课方案）：让qwen当评委逐片打分，无需额外模型、理解强，但慢、费钱、分数可能抖
- **BGE reranker**（工业常用）：专用小模型输出0~1相关度，快、便宜、稳定，但要本地下载模型（sentence-transformers）
- 注意：`bge-large-zh` 是本地模型，不能塞进 OpenAIEmbeddings 调用；阿里云用 DashScopeEmbeddings + text-embedding-v3

## Day 16 Agent 核心概念 + ReAct 思考范式（16_react_agent.py）

Agent 与 Chain 的区别：

| 对比项 | Chain（链） | Agent（智能体） |
|---|---|---|
| 执行路径 | 开发者写死，固定顺序 | 模型自己决定，动态 |
| 工具调用 | 固定调用 | 模型判断调不调、调哪个、调几次 |
| 循环次数 | 1 次 | 不确定，直到模型认为能回答 |

一句话：**Agent = LLM（大脑）+ Tools（手）+ 循环（控制流）+ Prompt（行为规范）**

### ReAct 思考范式

ReAct = **Reason（推理）+ Act（行动）**，每轮只输出一种内容，格式固定四段：

`思考 Thought → 行动 Action → 行动输入 Action Input → 观察 Observation（由程序填）`

整体链路：`提问 →(模型)思考/行动 → 程序执行工具 → 注入真实观察 → 拼回history → 再问模型 →(资料够)最终答案 /(不够)继续循环`

### 脚本四部件

- ① 大脑：`ChatOpenAI(temperature=0.0)`（保证 ReAct 格式稳定）
- ② 手：工具函数 + 映射表 `TOOLS = {"search_knowledge_base": search_knowledge_base}`（Agent 靠这张表把"文字工具名"翻译成真实函数调用）
- ③ 规范：REACT_PROMPT，规定四段格式 + 声明"观察由系统填，你不要自己编"
- ④ 控制流：`for step in range(1, max_steps+1)` 主循环

### 两个"关键"（漏写就复现"重复回答三遍"的 bug）

- **关键1 截断**：`text = re.split(r"观察[:：]", text)[0].strip()`
  模型常忍不住自己往下写"观察:xxx"，一旦自编观察后面推理全是幻觉 → 只要出现"观察"就砍掉后半段，真实结果由程序注入
- **关键2 记忆**：`history += f"{text}\n观察: {observation}\n"`
  把"模型输出 + 真实观察"存回上下文；上次重复调 3 遍，根因就是工具结果没存回 messages，模型看不到结果只能反复问

### 循环三种分支

- 情况A：`if "最终答案" in text:` → `re.split(r"最终答案[:：]", text)[-1]` 取答案并 return（结束）
- 情况B：既没行动也没答案 → 整个 text 当答案返回
- 情况C：`TOOLS.get(action)(action_input)` 真正执行工具 → 拼进 history → 进入下一轮
- `max_steps=5` 是死循环保护，超限返回"已达到最大轮数"

### 验证方法

- 相关题"校园卡丢了怎么补办要多少钱" → 第 1 轮检索、第 2 轮给答案 ✔
- 无关题"怎么炒番茄炒蛋" → 输出"根据现有资料无法回答" ✔ 拒答不幻觉

### 框架版对比

- 手写循环 ≈ `create_react_agent(llm, tools, prompt)` + `AgentExecutor(tools=tools, verbose=True, handle_parsing_errors=True)`
- prompt 里的 `{agent_scratchpad}` 就是框架替你维护的"思考-行动-观察"历史 = 手写的 `history`；说明框架只是"换了个壳"
- 注意：`.env` 只在 d:\rag-demo 目录生效，脚本放别处运行要写 `load_dotenv(r"d:\rag-demo\.env")`，否则报 `api_key must be set`

## 通用踩坑记录

| 类型 | 案例 | 教训 |
|------|------|------|
| 变量名 | `return score`（数字）误写成想要的 `return scored`（列表） | return前想清外面要的是一个值还是一批数据 |
| f-string | `f"[i]"` 原样输出字母i，`f"[{i}]"` 才替换成编号 | 变量必须用 {} 包裹 |
| 解包 | `for doc,i` 顺序写反；`for i,(doc,score)` 漏括号 | enumerate给(编号,元素)；嵌套对要用括号再拆 |
| 变量作用域 | for里拆包叫doc，print里却抄了上个循环的d | 循环体变量名要和本行for一致 |
| 引号 | 三引号闭合行 `回答:"""` 夹了中文引号，后续代码全被当字符串 | 闭合的"""单独干净一行，前面不夹任何引号 |
| 正则 | `re.split(r"观察[:：]", text)[0]` 漏了 `[0]`，拿到的是列表不是字符串 | split 返回列表，要取 `[0]` 才是字符串 |
| 字典取键 | 工具名对不上时用 `TOOLS[action]` 会 KeyError | 用 `TOOLS.get(action)` 更安全，取到 None 就先返回提示 |
| 循环边界 | `range(1, max_steps+1)` 忘 `+1` 会少跑一轮 | 闭区间写法要 `+1` |
| 环境变量 | 脚本放别处运行 `load_dotenv()` 找不到 .env，报 `api_key must be set` | 显式指定路径 `load_dotenv(r"d:\rag-demo\.env")` |
| 标点形近字 | 正则写 `r"观察[:；]"`，但提示词里用的是全角冒号 `：` | `；`(全角分号)、`：`(全角冒号)、`:`(半角冒号) 肉眼难分辨；正则必须和提示词用同一套冒号，稳妥写 `[:：]` 半角全角都收 |
| 只import未调用 | `from dotenv import load_dotenv` 写了，却漏掉 `load_dotenv()` 那一行 | import 只是把函数搬进来、并不执行；少写调用行就会报 `api_key must be set` |
| import 来源错 | `from langchain_text_splitters import PyPDFLoader, TextLoader` → ImportError | 加载器属 `langchain_community.document_loaders`，切片器才是 `langchain_text_splitters` |
