# 第二阶段学习笔记：LangChain + RAG 进阶

## Day 13 RAG 进阶：重排序 + 引用溯源 + 拒答去幻觉（13_advanced_rag.py）

基础 RAG 的三个问题及对策：

| 问题 | 方案 | 一句话原理 |
|---|---|---|
| 向量检索排序不准 | **重排序 Rerank** | 粗检索5片 → LLM逐片打0-10分 → 按分排序取top3 |
| 不知道答案出自哪 | **引用溯源 Citation** | 给文档编号[1][2][3]，prompt要求回答标注编号，末尾列文件名 |
| 资料没有也硬编（幻觉） | **拒答去幻觉** | 调LLM前看最高分，低于阈值5直接拒答，根本不调LLM |

整体链路：`粗检索(k=5) → LLM重排序 → top3 → 分数判断 →(合格)拼编号context → 带引用回答 /(不合格)直接拒答`

### 阶段A：LLM 重排序

- `rerank(question, docs, llm)`：每片文档拼进打分 prompt，`score = float(result.content.strip())`（LLM返回的是文本，要转数字才能排序）
- 成对存储 `scored.append([doc, score])`，排序 `scored.sort(key=lambda x: x[1], reverse=True)`（x[1]=取分数，reverse=降序）
- **必须 `return scored`**（整个列表），不能 return score（只剩一个数字，下游会崩）
- 列表推导式只留文档丢分数：`[doc for doc, score in scored]`
  - for 后的 `doc, score` 是**解包**（接住每对里的两个值）；for 前的 `doc` 是每轮要收集进新列表的值

### 阶段B：引用溯源

- `for i, doc in enumerate(top3, 1)`：第二个参数1让编号从1开始（默认0）
- 来源取元数据：`doc.metadata.get("source", "未知来源")` → `os.path.basename()` 只留文件名
- 编号拼上下文：`f"[{i}] {doc.page_content}"`，三片用 `"\n\n".join(...)` 连接（空一行分清边界）
- prompt 三句约束：①只能根据资料答 ②标注数字编号 ③没答案就说无法回答
- 回答取 `answer.content`（AIMessage 对象的文本属性）

### 阶段C：拒答去幻觉

- 阈值常量 `SCORE_THRESHOLD = 5.0`（经验值：实测相关片10分、无关片0分，取中间5）
- `top_score = top3[0][1]`：`top3[0]`是第1名的[doc,分数]，再`[1]`取分数（连续下标，中间无逗号）
- `if top_score < 阈值: 直接print拒答 else: 执行整个阶段B`
  - 拒答分支不拼context、不调LLM → 省钱且绝不可能幻觉（硬门槛，比prompt里"请不要编造"的软约束可靠）
- top3 每项变成 `[doc, score]` 后，循环解包要写 `for i, (doc, score) in enumerate(...)`（括号不能省）

### 验证方法

- 相关问题"没按时还书会怎么样" → 第1名10分 → 正常回答，逾期规则后带[1]
- 无关问题"怎么炒番茄炒蛋" → 全0分 → 只输出"根据现有资料无法回答"，无引用来源段

### 两条重排序技术路线对比

- **LLM 打分**（本课方案）：让qwen当评委逐片打分，无需额外模型、理解强，但慢、费钱、分数可能抖
- **BGE reranker**（工业常用）：专用小模型输出0~1相关度，快、便宜、稳定，但要本地下载模型（sentence-transformers）
- 注意：`bge-large-zh` 是本地模型，不能塞进 OpenAIEmbeddings 调用；阿里云用 DashScopeEmbeddings + text-embedding-v3

## 通用踩坑记录

| 类型 | 案例 | 教训 |
|------|------|------|
| 变量名 | `return score`（数字）误写成想要的 `return scored`（列表） | return前想清外面要的是一个值还是一批数据 |
| f-string | `f"[i]"` 原样输出字母i，`f"[{i}]"` 才替换成编号 | 变量必须用 {} 包裹 |
| 解包 | `for doc,i` 顺序写反；`for i,(doc,score)` 漏括号 | enumerate给(编号,元素)；嵌套对要用括号再拆 |
| 变量作用域 | for里拆包叫doc，print里却抄了上个循环的d | 循环体变量名要和本行for一致 |
| 引号 | 三引号闭合行 `回答:"""` 夹了中文引号，后续代码全被当字符串 | 闭合的"""单独干净一行，前面不夹任何引号 |
